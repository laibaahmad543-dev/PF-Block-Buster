A brick-breaking game developed in C++ using SFML 3.0.2 for our semester project.

# Game Features

- Three types of bricks with different durability
- Paddle movement and ball collision
- Score and lives tracking
- New Game, Continue and Exit options
- Saving and loading game progress
- Win and Game Over screens
- Wide paddle and extra life power-ups

# Game Controls

 Key : Action 

 Left Arrow / A : Move paddle left 
 Right Arrow / D : Move paddle right 
 Space : Launch the ball 
 Escape : Save game and return to menu 
 Up / Down Arrow : Navigate menu 
 Enter : Select menu option 

# How to Run

1. Clone or download the GitHub repository.
2. Install Visual Studio and SFML 3.0.2.
3. Open the project solution in Visual Studio.
4. Configure the SFML include and library directories.
5. Ensure level.txt, background.png and gamefont.ttf are available in the working directory.
6. Build and run the project using Ctrl + F5.

# Power-Ups

- W: Increases paddle width to 150 pixels for 600 frames.
- +: Grants one additional life.
